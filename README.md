The Hotel Recommendation System is a Minor Machine Learning Project developed using Python and Linear Regression.

This system predicts a customer satisfaction score (out of 10) based on important hotel features such as:

💰 Budget
📍 Distance from city center
⭐ Hotel Rating
🛎 Amenities
🍽 Food Quality

Based on the predicted score, the system provides a clear recommendation to help users decide whether to book the hotel.

🎯 Project Objective
To understand the concept of Linear Regression
To apply Supervised Learning techniques
To build a simple real-time prediction system
To interpret numerical prediction results

This project is ideal for beginners learning Machine Learning fundamentals.

📊 Input Features

The model uses the following features for prediction:

Feature	Description
Budget	User’s budget in ₹
Distance	Distance from city center (km)
Rating	Preferred hotel rating (1–5)
Amenities	Number of amenities (1–5)
Food Quality	Food quality preference (1–5)
⚙️ How It Works
A sample dataset is created manually.
The dataset is divided into training and testing data.
A Linear Regression model is trained using the training data.
The user enters their hotel preferences.
The model predicts the satisfaction score.
A recommendation is displayed based on the predicted score.
